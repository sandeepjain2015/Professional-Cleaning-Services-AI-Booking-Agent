# 🧼 Professional Cleaning Services AI Booking Agent

An AI-powered cleaning service booking platform built using Gradio, DeepSeek AI, SQLite, and Railway deployment.

✅ Modern Glassmorphism UI
✅ AI Booking Summary Generation

✅ Smart Cleaning Recommendations
✅ Dynamic Add-on Services
✅ Email Notifications
✅ SQLite Database Storage
✅ Railway Deployment Ready
✅ Responsive Design
✅ Premium Dropdown Styling

# 🛠️ Tech Stack

* Python
* Gradio
* DeepSeek API

# 📦 Installation

Clone repository:

```bash
git clone https://github.com/sandeepjain2015/Professional-Cleaning-Services-AI-Booking-Agent.git

cd Professional-Cleaning-Services-AI-Booking-Agent
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# 🔑 Environment Variables

Create `.env` file:

```env
DEEPSEEK_API_KEY=your_deepseek_api_key
SERPER_API_KEY=your_serper_api_key

RESEND_API_KEY=your_resend_api_key
ADMIN_EMAIL=your_email@gmail.com
```

---

# ▶️ Run Locally

```bash
python app.py
```

Open:

```text
http://127.0.0.1:7860
```

---

# ☁️ Deploy on Railway
